# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Do not open a public GitHub issue, discussion or pull request, and do not post details in public channels.

Use GitHub's private reporting: open the [Security tab](https://github.com/ihsn/nada/security) of this repository and choose **Report a vulnerability**.

Please include:

* a description of the issue and the possible impact
* the NADA version, PHP version and database (MySQL, MariaDB or Microsoft SQL Server)
* steps to reproduce, or a proof of concept
* any suggested fix, if you have one

Do not include real survey data, personal information, passwords or API keys. Use sample values.

## What to expect

* We will acknowledge your report and keep you updated as we investigate.
* Confirmed vulnerabilities are fixed in a new release, and the release notes will say so.
* Please give us reasonable time to release a fix before you disclose the issue publicly.

## Supported versions

Security fixes are made in the latest released version. Please upgrade to the latest release before reporting, and check that the issue still exists.

## Hardening your installation

For guidance on securing a NADA installation, see the [NADA documentation](https://ihsn.github.io/nada-documentation/).
