# Contributing to NADA

Thank you for your interest in improving NADA. This page explains how to report problems, suggest changes and submit code.

## Reporting bugs and requesting features

Open an issue on [GitHub Issues](https://github.com/ihsn/nada/issues). Please include:

* the NADA version (or the tag or commit you are running)
* the PHP version and the database you use (MySQL, MariaDB or Microsoft SQL Server)
* what you expected to happen, what happened instead, and the steps to reproduce it
* any error messages from the browser, the PHP log or the application log

Do **not** attach real survey data, microdata, personal information, passwords or API keys. Replace them with sample values.

To report a security vulnerability, do not open a public issue. Follow [SECURITY.md](SECURITY.md).

## Submitting changes

1. Fork the repository and create a branch from `develop`.
2. Make your change, keeping it focused on one topic.
3. Open a pull request against the `develop` branch and describe what the change does and why.

`main` holds released versions, so please do not open pull requests against it.

## AI-assisted contributions

You may use AI tools to help write code, tests or documentation. If a pull request contains substantial AI-assisted work, say so in the pull request description. You are responsible for every change you submit: you must understand it, have tested it, and be able to explain it. You are also responsible for making sure the contribution can be licensed under the project's license. Pull requests that are unreviewed AI output may be closed.
